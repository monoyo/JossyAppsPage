# JossyApps GitHub Pages

Static website containing product, Privacy Policy and Terms pages.

## Publish
1. Create a public GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save.

## Before publishing
Replace the placeholder contact information and review each Privacy Policy and Terms page so that it accurately describes the application's real data practices and services.
